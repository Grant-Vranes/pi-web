# 会话历史非当日时间戳显示设计

## 目标

在左侧对话历史的每个会话条目中，保留当天会话的相对时间显示，例如“2小时前”；昨天及更早会话不再显示“x天前”，改为显示本地化的完整日期和精确到秒的时间。

## 范围

- 仅调整左侧会话条目的辅助时间文本。
- 不调整会话排序、日期分组标题、分组折叠状态、tooltip 或其他消息时间显示。

## 设计

时间展示逻辑集中在 `lib/i18n/format.ts` 的会话时间格式化函数中：

1. 根据浏览器本地日历日判断时间戳是否属于今天。
2. 当天会话沿用现有 `Intl.RelativeTimeFormat` 相对时间输出。
3. 非当天会话使用 `Intl.DateTimeFormat` 输出数值化的年、月、日、小时、分钟和秒，采用当前 UI locale。
4. `components/SessionSidebar.tsx` 继续仅调用该格式化函数，不引入新的日期判断或字符串拼接。

## 测试

在 `lib/i18n/format.test.mjs` 中覆盖：

- 当天时间戳仍输出相对时间。
- 昨天的时间戳输出日期和 `HH:mm:ss` 级时间，而非“1天前”。
- 更早日期同样输出完整日期和秒级时间。
- 中英文 locale 都使用本地化格式。

## 错误与边界

沿用现有 `Date` 与 `Intl` 行为；该格式化函数不改变无效日期处理方式。日界以浏览器本地午夜为准，而非过去 24 小时的滚动窗口。
